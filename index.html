04 / MODEL CONTEXT PROTOCOL · BUILT FOR PRODUCTION

Give an AI agent the ability to serve customers and place real orders.

I built a production MCP server as a reusable commerce-tool layer—not a single chatbot. Connect it to any MCP-capable interface or agent and it can find products, prepare a live quote, place the customer’s requested Cash on Delivery order after they approve the total, and track that order. The agent experience can change; the business tools do not need to be rebuilt.

A GUARDED ORDER JOURNEY

Quote first. Confirm only with approval.

The agent gets current product and delivery information, presents a complete quote, and waits for the customer before placing an order.

  1. 01
    DiscoverFind products, availability and tier prices.
  2. 02
    QuoteCalculate item totals, savings and city-based delivery fees.
  3. 03
    Place the orderOnce the customer agrees to the quote, the agent submits their requested items, contact and delivery details; the server creates the COD order.
  4. 04
    TrackLook up order status and delivery details by order ID.

The tools agents can call

list_products

Browse rice products and tier pricing, with optional in-stock and hotel/restaurant filters.

search_products

Search products by name, with optional availability and hotel/restaurant filters.

get_product_details

Retrieve a product’s full details and available price tiers by product ID.

quote_order

Build a server-side quote with tier pricing and city-based delivery fees; quotes expire after 30 minutes and accept up to 20 line items (up to 1,000 kg each).

confirm_order

Turn the customer’s approved quote into a real COD order in the commerce system, including customer, items and delivery address; the call includes an idempotency key.

track_order

Check order status, items and delivery details by order ID, with optional phone-number verification.

Plug the same tools into the interface you choose

MCP-compatible AI clients

Use the remote server as an MCP connector for supported ChatGPT and Claude integrations, or connect clients such as OpenCode. Product lookup, quotes and order placement stay on this one server.

Your own chat or voice agent

Connect a website agent, an ElevenLabs voice experience, or an agent built with a framework that supports MCP. The earlier first-party OpenAI Agents SDK chat was retired; its agent interface can be brought back or replaced without recreating the MCP commerce tools.

Ready-to-use agent prompt

yousuf_rice_customer_service guides the agent to verify products, present the full quote and wait for explicit agreement before ordering, follow delivery/payment policies, and escalate sensitive cases.

Trust built into the workflow: product and prices come from the live catalog; the server checks quote expiry and delivery city before creating an order; the customer-service prompt tells the agent to present the full quote and wait for explicit approval before placing it. The server never asks for GPS coordinates. Optional Bearer-token authentication uses timing-safe comparison when configured.
